## 已复现并修复

源版本 `_ground_height()` 用最小 Y 寻找方块最低角点，但相机坐标 +Y 向下，应该取最大 Y。旋转方块在桌边时会把桌面和地面支撑判反。两个固定旋转姿态的回归测试在修复前失败；修复只将 `np.min` 改为 `np.max`，保持其余接触策略。

## 验证范围和待验收项

使用项目已有 Python 3.10.11、Open3D 0.18.0 环境，执行 `python -B -m unittest discover -s tests -v`，覆盖原泥坯拓扑/形状/位姿，以及标签槽位、吸附、丢帧超时、释放延迟和桌边旋转支撑。无相机场景另通过 `clay_demo.py --verify-dir` 复核。

本次未使用真实相机或 Orbbec 实机，不将以下事项计为已验收：

- 左右手标签短暂错误或重复时的实际跟踪稳定性。现有槽位分配基于标签，不含前帧位置匹配。
- 主手候选切换：抓取中按距离选择最近检测手，且未重新绑定抓取相对旋转；需实测换手时是否跳变。
- 捏合阈值、吸附与释放延迟在真实输入下的手感与误触率。
- 接触算法是最低角点支撑近似，未求方块与桌面矩形的完整接触区域。

因此本分支准备为草稿 PR，等待上述真实输入和双手场景验收后再合入 main。
